# Glossary

Shared vocabulary for all ScaleScape documents. Terms are listed alphabetically.

| Term | Definition |
| --- | --- |
| Brightness chain | The ordering of diatonic modes from brightest to darkest: Lydian, Major, Mixolydian, Dorian, Natural minor, Phrygian, Locrian. Each adjacent pair differs by exactly one degree. |
| Broad contrast | Two scales or modes that differ in several degrees, used for introductory listening without asking for one defining note. |
| Caption | The single short sentence attached to an interactive explanation. The maximum unit of didactic text in the MVP. |
| Characteristic degree | The scale degree that most distinguishes a mode from its reference mode. Stored as explicit formula metadata. |
| Chord tone | A scale degree belonging to the tonic triad; it may also carry another role such as characteristic. |
| Core learning loop | Listen, Recognize, Locate, Play, Contextualize, then Listen again. |
| Correlation ID | An ephemeral identifier that groups logs and spans from one use case without identifying a user. |
| Degree | The ordinal position of a note within a scale, starting at one for the root. |
| Diagnostic mode | An explicitly enabled local mode that records additional bounded, redacted debugging information. |
| Drone | A sustained tonic note played under exploration and exercises. |
| Ear Gym | The practice view containing short recognition exercises. |
| Focused comparison | Two related modes that differ by exactly one degree, used for focused listening and identification. |
| Guided Start | The newcomer-friendly path that begins with hearing and manipulating a difference before introducing theory vocabulary. |
| Insight transfer | The ability to apply a learned concept to a new root or instrument. The primary signal that learning happened. |
| Interval | The relationship between a scale root and another note, described by semitone distance and quality. |
| Interval quality | The major, minor, perfect, augmented, or diminished classification of an interval. |
| Diagnostics exporter | An application adapter that creates a sanitized user-requested file from a diagnostic snapshot; it is not an active log sink. |
| Log sink | A persistence adapter that receives structured log batches, such as memory, IndexedDB, filesystem, or database storage. |
| Mode | A rotation of a parent scale formula, treated as a scale with its own tonic. |
| Octave | The register of a note; pitch classes repeat every twelve semitones. |
| Pedal | A sustained tonic-and-fifth accompaniment, richer than a single drone. |
| Performance span | A correlated operation measured with a monotonic clock and completed with an outcome and duration. |
| Pitch class | One of the twelve chromatic positions, independent of octave. |
| Reference mode | The close neighboring mode used in a focused one-degree comparison. |
| Role | A semantic function carried by a scale note. A note may have multiple roles, while one primary role controls visual emphasis. |
| Scale formula | An ordered set of degrees and semitone offsets from a root, independent of any specific root. |
| Scale instance | A formula applied to a concrete root, with resolved notes, intervals, roles, and spellings. |
| Semitone | The smallest pitch distance in the chromatic system; one fret or one piano key step. |
| Streak | The count of consecutive correct Ear Gym answers. It resets on an incorrect answer. |
| Tonic | Degree one; the root and point of rest of a scale or mode. |
